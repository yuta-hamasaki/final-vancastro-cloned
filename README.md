
##  自動車学校向け 生徒入会・レッスン予約システム
## プロジェクト概要
このプロジェクトは、カナダのとある自動車学校が抱えていた、レッスン予約、契約書作成、請求書作成、シフト管理といった一連の生徒・講師間のアナログ作業を一括管理し、効率化するために開発されました。

私たちはチーム開発により、生徒の入会からレッスン予約、外部会計システムとの連携までを網羅した統合管理システムを構築することで、クライアントの業務プロセスにおける非効率性を解消しました。

## 課題	解決策
レッスン予約や書類作成のアナログ作業	生徒入会・レッスン予約・請求書作成機能の一元管理によるデジタル化
既存の会計ツールの運用維持	外部会計システムとの API 連携によるデータ連携の自動化

## チーム体制と担当役割
このプロジェクトは学校の最終課題として実施され、私は以下の役割を担いました。

## 役割名:	担当内容
プロジェクトマネージャー: 	技術選定、クライアントとの要件定義・進捗ミーティング、チームのタスク管理、スケジュール調整など。
フルスタックエンジニア： バックエンド開発全般（Node.js/Express, PostgreSQL）。特に外部会計システム(QuickBook)とのセキュアな API 接続モジュールの設計・実装を担当。また、フロントエンドでは契約書サイン機能の実装、動的 PDF 生成・保存、ファイナンス関連データの表示など、複雑なバックエンド連携を必要とする主要機能を担当。

## システム構成図
機能一覧（画面イメージ）
クライアントの抱える問題を解決するため、以下の主要機能を開発しました。

## 画面名	機能概要	画面イメージ
トップ画面	サービスのランディングページ（LP）として構成し、訪問者が内容を理解しやすくし、入会を促進。	
ログイン画面	Google ログインを実装し、ユーザー登録・ログインの手間を削減。	
自動返信一覧/設定	設定中の自動返信を一覧表示し、ON/OFF を切り替え可能。キーワードや時間条件など詳細な設定が可能。	
返信テンプレート一覧/設定	自動返信文の管理。Instagram 上でのプレビュー機能で、稼働イメージを確認可能。	
タグ一覧/ユーザー一覧	自動返信ユーザーへのタグ付け機能により、キャンペーン参加者などを効率的に管理し、後のマーケティングに活用。

## 今後の展望（ロードマップ）
本プロジェクトの成功を受け、サービスをさらに発展させるため、以下の 4 つのフェーズでの開発を計画しています。

フェーズ 1：機能強化

既存の UI/UX の見直しと改善により、直感的で操作性の高いデザインに刷新します。

フェーズ 2：新機能の追加

ユーザーフィードバックや市場調査に基づき、新たな価値を提供できる機能（例: 講師向けシフト自動調整機能など）を開発・導入します。

フェーズ 3：パフォーマンスの最適化

システムのレスポンス時間、データの読み込み速度を短縮し、ユーザーにストレスのない快適な操作感を提供します。

フェーズ 4：安定性の向上

システムの耐障害性を高め、長期的なサービス提供を見据えた安定運用のための改善と定期メンテナンスを実施します。
