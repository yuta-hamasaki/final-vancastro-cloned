# 🚗 自動車学校向け 生徒入会・レッスン予約システム

## 📌 プロジェクト概要
本プロジェクトは、カナダの自動車学校における **レッスン予約・契約書作成・請求書作成・シフト管理** といったアナログ業務を一括管理し、効率化するために開発されました。  

チーム開発により、生徒の入会からレッスン予約、外部会計システムとの連携までを網羅した **統合管理システム** を構築し、クライアントの業務プロセスにおける非効率性を解消しました。

---

## ⚡ 課題と解決策
| 課題 | 解決策 |
|------|--------|
| レッスン予約や書類作成のアナログ作業 | 生徒入会・レッスン予約・請求書作成を一元管理し、完全デジタル化 |
| 既存の会計ツールの運用維持 | 外部会計システム（QuickBook）との API 連携によりデータ連携を自動化 |

---

## 👥 チーム体制と担当役割
本プロジェクトは学校の最終課題として実施されました。私は以下の役割を担当しました。  

- **プロジェクトマネージャー**  
  - 技術選定  
  - クライアントとの要件定義・進捗ミーティング  
  - チームのタスク管理、スケジュール調整  

- **フルスタックエンジニア**  
  - **バックエンド開発**（Node.js/Express, PostgreSQL）  
    - 特に QuickBook API とのセキュアな接続モジュールの設計・実装を担当  
  - **フロントエンド開発**  
    - 契約書サイン機能の実装  
    - 動的 PDF 生成・保存  
    - ファイナンス関連データの表示など、複雑なバックエンド連携を必要とする機能を担当  

---

## 🛠 技術スタック
- **Frontend**: Next.js (TypeScript), TailwindCSS  
- **Backend**: Node.js (Express/TypeScript), Prisma  
- **Database**: PostgreSQL (Supabase)  
- **Infrastructure**: Vercel, Supabase  
- **Design**: Figma  
- **Auth**: Clerk  
- **Third-Party API**: QuickBook API  
- **Others**: ESLint, Prettier, Git, GitHub  

---

## 🖥 システム構成と機能一覧
クライアントの抱える課題を解決するため、以下の主要機能を実装しました。  

| 画面名 | 機能概要 |
|--------|-----------|
| トップ画面 | サービスのランディングページ（入会促進） |
| ログイン画面 | Google ログイン（Clerk）による認証 |
| 契約画面 | 契約書への電子サイン機能 |
| ダッシュボード（生徒用） | レッスン購入・予約、契約書確認・印刷 |
| ダッシュボード（講師用） | スケジュール管理、予約確認、請求書発行、移動時間登録 |

# 開発者向け

## パッケージインストール

```bash
npm i
```

## 環境変数設定

`.env` をfrontend & backend の各ルートディレクトリに作成し、それぞれの中身はリクエストしてください。

## 作業ブランチ

`dev`ブランチから、ブランチを切ってください。
ブランチ命名
新機能追加 `feat/hoge`
バグ修正 `fix/hoge`

## ローカルサーバー起動

```bash
npm run dev
```

## 今後の展望（ロードマップ）
本プロジェクトの成功を受け、サービスをさらに発展させるため、以下の 4 つのフェーズでの開発を計画しています。

フェーズ 1：機能強化

既存の UI/UX の見直しと改善により、直感的で操作性の高いデザインに刷新します。

フェーズ 2：新機能の追加

ユーザーフィードバックや市場調査に基づき、新たな価値を提供できる機能（例: 講師向けシフト自動調整機能など）を開発・導入します。

フェーズ 3：パフォーマンスの最適化

システムのレスポンス時間、データの読み込み速度を短縮し、ユーザーにストレスのない快適な操作感を提供します。

フェーズ 4：安定性の向上

システムの耐障害性を高め、長期的なサービス提供を見据えた安定運用のための改善と定期メンテナンスを実施します。
